# Warren v0.2.0

Rilis resmi Warren v0.2.0 — Personal Workspace untuk SSH Terminal & Hermes Agent Companion.

### Fitur Utama:
- **Multi-Session Terminal**: Terminal interaktif berbasis xterm.js v6 dengan tab multi-sesi, manajemen PTY, konfirmasi paste, dan proteksi fingerprint host SSH.
- **Hermes Agent Companion**: Percakapan asisten cerdas langsung ke server Hermes dengan streaming respons SSE, pelacakan aktivitas alat, dan isolasi total dari terminal.
- **Stronghold Local Vault**: Brankas terenkripsi lokal dengan master password 12+ karakter dan derivasi Argon2.
- **In-App Auto-Updater**: Pembaruan aplikasi langsung dari menu Pengaturan dengan verifikasi signature Minisign ED25519 dan verifikasi hash SHA-256.
